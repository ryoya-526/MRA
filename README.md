# MRA Repository Structure

This repository now keeps the Angular application inside the [`MRA/`](./MRA/) subdirectory.

To work with the project:

1. Change into the nested project folder:
   ```bash
   cd MRA
   ```
2. Install dependencies if you have not already:
   ```bash
   npm install
   ```
3. Run the usual Angular CLI commands from inside that directory, for example:
   ```bash
   npm run start
   npm run build
   npm run test
   ```

All existing project files—including the Angular workspace configuration, source
code, and documentation—have moved beneath the `MRA/` folder.
